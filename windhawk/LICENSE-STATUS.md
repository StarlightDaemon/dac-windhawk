# Licensing status

The original Display Activity Controls for Windhawk source, tests and tooling
are distributed under the [MIT license](LICENSE.md), matching the license the
operator selected when creating `StarlightDaemon/dac-windhawk` on 2026-10-07.
The complete mod source embeds that notice so it travels with a single-file copy.

This grant does not assign rights to the inherited OLED Aegis standalone
application or artwork. Those files are excluded from the new repository export.
The historical source comparison and lineage are retained in
[PROVENANCE](docs/PROVENANCE.md). Dependency terms and Fujin's MIT notice remain
in [THIRD_PARTY_NOTICES](docs/THIRD_PARTY_NOTICES.md).

Earlier reports stating that original-code licensing was unselected describe
prior local checkpoints. This file records the current publication decision.
